# EduGenie: Google Gemini Powered Learning Assistant

## Project Overview

EduGenie is an AI-powered learning assistant designed to help students
learn, understand and practice educational topics using Google Gemini.

## Features

- Question and Answer
- Topic Explanation
- Quiz Generation
- Text Summarization
- Personalized Learning Path

## Technologies Used

- Python
- FastAPI
- Google Gemini API
- Jinja2
- HTML
- CSS
- Uvicorn
